# Source and sample provenance

The bundled `examples/portfolio/` page, procedural WebGL behavior, SVG illustrations, and example text were newly authored for this project's self-contained portfolio demonstration. They do not embed or download the original website's 3D models, original runtime JavaScript, texture library, font atlas, music, client work or branding. Any example names and descriptions are demonstration content, not claims of commissioned work, customers or real usage.

`portfolio-v1` is a distinct trusted runtime profile using the project's existing manifest, selection and immutable publishing flow. It is not evidence that `legacy-six-scenes-v1` or the original 3D scene has been visually reproduced or licensed. The original runtime remains an explicitly authorized optional input; it is excluded from the default Docker image and base test dependency set.

Inherited repository code, historical CMS records, old HTML, restoration scripts and compatibility transforms predate this change. Their presence does not establish authorship, redistribution rights or an open-source license. The repository owner must decide licensing after reviewing those materials; this change intentionally does not assign a permissive license to unknown inherited material. See THIRD_PARTY.md for the inventory boundary.

Operator-owned uploads, authorized runtime bundles, database backups, S3 objects and private deployment configuration are not shipped source artifacts and must not enter the build context or repository. Tests use newly created fixtures and do not turn fixture success into a claim about production or original proprietary bytes.
