# 个人网站管理后台与资源存储设计

日期：2026-10-12
状态：设计已整理，等待用户审阅；尚未实施。

## 1. 已确认的目标

- 将现有 3D 个人网站整理为可保存到 GitHub、供他人独立部署的项目。
- 提供公网可用的管理后台及登录认证。
- 后台管理各场景资源、作品、文案、链接与音乐。
- 上传支持本地磁盘与通用 S3 兼容对象存储，不在首版加入各厂商专用 SDK。
- 同时支持直接引用外部资源 URL；外链不是第三种上传存储，不默认下载或转存。
- 保留当前 Jian Dan 模型、黑洞效果、作品和其他本地修改作为现有站点的初始数据。

## 2. 产品边界与实施顺序

首版是单站点、单管理员、单服务实例的自托管应用。不是多租户建站平台，不开放公众注册，不做团队权限、在线着色器代码编辑、自动全库迁移或任意 3D 场景编辑器。

按可独立验证的阶段推进，每阶段完成后仍能运行前台：

1. 安全基础：管理登录、受保护接口、公共与私有目录隔离、配置数据库。
2. 资源基础：资源库、本地与 S3 适配器、外链引用、上传及校验。
3. 页面接入：作品、场景资源、文案与音乐的配置编辑、预览、发布与版本恢复。
4. 分发准备：部署说明、持久化目录、示例配置、合法可分发资源清单与回归测试。

以上是同一产品的交付阶段；每阶段分别测试，不把上传成功等同于场景替换成功。

## 3. 现状及必须修正的问题

- `editor.html` 已有作品编辑界面，可复用其字段和数据映射，不沿用不安全的写入方式。
- `server.js` 的作品保存和构建接口没有认证，必须纳入统一鉴权或删除旧入口，不能留下绕过路径。
- 当前 `express.static(__dirname)` 暴露范围过大，改为明确的公共文件和目录白名单。
- 当前 `patch-search-text.js` 含硬编码默认配置，后台保存不得盲目执行该脚本，避免覆盖已有内容。
- 原站资源代理、下载和缓存属于开发辅助功能，生产默认禁用；已有资源缺失应给出具体诊断。
- `assets/` 当前被 Git 忽略，因此现状不能保证克隆仓库后即可运行。分发前须提供可再分发的运行资源包或清晰的自备资源流程，不自动把现有资源全量加入 Git。

## 4. 页面与交互

后台入口 `/admin`，未登录进入登录页面。界面使用中文，左侧模块导航，右侧编辑内容，保存状态始终可见。

- 概览：配置状态、资源统计、默认存储、近期操作和失败任务。
- 页面管理：Home、About、Work、TreeScene、CleanRoom、Footer 六个场景。
- 作品管理：名称、分类、顺序、简介、日期、封面、视频和链接。
- 资源库：按图片、视频、音频、模型筛选，显示来源、大小、预览、处理状态与引用位置。
- 网站设置：标题、导航文案、个人介绍、联系方式、社交链接和音乐列表。
- 存储设置：本地存储、S3 配置、默认上传位置、测试连接。
- 版本记录：预览历史配置差异、恢复为草稿，再确认发布。
- 账号安全：修改密码、退出登录。

所有资源字段共用资源选择器：选择已有资源 / 上传文件 / 粘贴外链。上传时允许选择存储位置，默认使用全站默认值。

场景编辑只开放有明确映射和校验的字段：模型引用及转换参数、贴图/媒体引用、文字/链接，以及已命名的效果参数。其余底层字段可在资源清单中只读展示，不提供任意 JSON 或任意代码执行入口。

## 5. 服务与数据组织

保留现有 Node 服务作为单一应用入口，不重写 3D 渲染引擎。新增独立的认证、配置、资源、存储、处理任务和前台适配模块；公共前台与管理后台共享服务但隔离数据接口。

- SQLite 保存账号、会话、存储配置、资源元数据、配置版本与任务状态。
- 服务端 `data/` 存放私有数据库、备份与处理中间文件，不受静态服务托管。
- 本地上传存放在持久化 `data/uploads/`，仅通过受控媒体路由读取登记为公开的资源。
- 核心表包括管理员、会话、存储配置、资源、配置版本、任务和审计事件。
- 每项资源记录稳定 ID、来源类型、所属存储配置 ID、对象键或外链、原名、类型、大小、校验值、处理状态；不依赖单一全局域名推算所有旧文件。
- 页面草稿与已发布版本分离；公开接口只输出当前已发布的展示字段，不输出账号、密钥、草稿和内部路径。
- 保存与发布带版本号，旧版本编辑遇到冲突时提示刷新，不静默覆盖更新。
- 用户输入的文案按文本处理；链接仅接受允许的协议，不拼接到可执行脚本或未经处理的 HTML。

## 6. 认证与部署安全

- 首次管理员账号通过服务器端交互初始化命令创建，不提供可被公网访客抢占的无保护注册接口，不设通用默认密码。
- 密码使用成熟的密码哈希方案，盐独立；不存储明文或可逆密码。
- 使用服务端会话，登录后轮换会话 ID，Cookie 为 HttpOnly、SameSite，公网 HTTPS 下启用 Secure。
- 会话空闲 12 小时或创建 7 天后过期；退出及改密使相关会话失效。
- 登录接口按来源与账号限流，失败提示不泄露账号是否存在；本机 HTTP 开发模式与生产模式明确区分。
- 写入接口实施会话检查、CSRF 防护与来源校验；公开跨域管理请求默认不允许。
- 反向代理信任范围由部署配置显式指定，不无条件信任转发头。
- 找回密码由服务器端管理命令完成，首版不增加邮件找回服务。
- 公共媒体服务禁止目录列出、路径穿越、符号链接越界；源文件、配置、数据库和备份不得公开。

## 7. 存储适配器

统一适配器负责写入、查询对象元数据、读取公开 URL 或媒体流，以及删除指定登记对象。删除能力不等同于后台默认提供永久删除。

### 本地存储

上传写入服务器持久化目录，使用服务端生成的对象键，原始文件名只作展示。开发时服务器是当前电脑，部署后是远端服务器，不是访问后台者的电脑。

### S3 兼容存储

配置包括名称、Endpoint、Region、Bucket、Access Key ID、Secret Access Key、可选 Session Token、对象前缀、公共访问基础 URL、路径风格开关。

- API Endpoint 与公开访问 URL 分开配置；只有确认需要兼容模式时才调整路径风格。
- 服务端 SDK 完成上传，首版不做浏览器直接获得长期密钥的上传方案。
- 上传流式处理并限制并发与大小；失败不会生成可发布资源，失败的分片上传应清理。
- 上传权限只作用于配置的桶和项目对象前缀；后台不创建桶，不自动修改桶权限或设置全桶公开。
- 首版支持公开可读取的站点资源 URL（可使用独立 CDN 域名），不实现私有桶临时签名 URL 自动刷新播放。
- S3 API 写入成功与公开 URL 可读取是两个不同状态，发布前要检查后者。
- “测试连接”默认只读检查权限；另设明确的“测试上传”动作，显示会创建并清理测试对象，使用隔离随机键且不覆盖已有对象。
- 生产默认要求 HTTPS Endpoint；私网或本机 S3 端点必须通过部署环境白名单显式允许，防止后台请求被用来访问非授权内部服务。
- 不承诺所有 S3 厂商完全兼容；记录实测环境和已验证操作。

### 密钥与配置变更

- 密钥服务端加密保存，部署环境提供独立主密钥；主密钥丢失需重新填写云凭证。
- API 只返回已配置标志和脱敏信息，编辑时留空表示保留原密钥，清除凭证须明确动作。
- 日志、错误响应、配置导出和 Git 仓库均不得含凭证。
- 切换默认存储只影响新上传；旧资源继续引用原存储配置。
- 已有资源引用的 Endpoint、Bucket、前缀等关键字段不可原地改为不同位置，应新建存储配置。引用中的配置不可删除；密钥允许轮换。
- 首版不自动迁移已有文件，也不自动删除旧存储对象。

## 8. 外链、上传与模型处理

- 外链只接受生产 HTTPS 资源地址，不接受脚本协议、本地文件路径、带用户密码的 URL。
- 注册外链不默认由服务器下载；优先在浏览器实际媒体/贴图使用路径验证，提示跨域、防盗链、失效或不支持的媒体格式。
- 如处理确实需要服务端抓取远程模型，须显式选择导入并执行 URL/DNS/重定向校验、大小上限和超时，阻止未授权内网及元数据端点访问。
- 管理后台不预览执行上传的 HTML、脚本或未经清洗的 SVG。初版允许常见栅格图片、MP4/WebM、MP3/WAV/OGG 与 GLB，按实际文件特征、大小和目标字段校验，不只看扩展名。
- 默认大小上限：图片 25 MiB、音频 100 MiB、模型 200 MiB、视频 1 GiB；部署者可调整，服务器与代理限制须一致。
- 超大上传、处理任务设置取消、超时和临时文件清理；前端展示上传与处理两个阶段。
- 当前引擎不能直接消费任意 GLB；GLB 保留原始文件，后台转换为引擎几何格式，并记录派生资源。
- 首版模型支持静态三角网格；骨骼动画、蒙皮和不支持的压缩扩展明确拒绝。正确处理节点变换、多网格与法线；大小/方向参数由用户调整。保留现有场景材质，不承诺导入 GLB 自带材质。
- 外链模型同样必须满足目标字段格式，不能把 GLB URL 直接塞给 Draco BIN 加载器。
- 替换模型、贴图等资源创建新记录；删除先解除引用并进入回收状态，已发布或历史版本引用资源不得物理删除。

## 9. 前台适配与发布

建立显式的“场景字段 → 配置键/资源槽位”映射；先从当前现场读取初始值，不用旧默认模板覆盖。

普通文案、媒体和链接由配置适配层消费。对于打包代码中硬编码的字段，采用可重复验证的定向接入，不在每次保存时对整份文件做无约束替换。

- 草稿保存不影响访客。预览必须显示草稿效果，并且草稿入口受认证保护。
- 发布流程先校验引用、生成所需字体/模型等派生文件，再创建完整不可变版本；版本准备完毕后事务切换当前版本指针。
- 生成或验证失败保留旧发布版本，不出现半更新状态。运行时根据同一个版本 ID 读取配套配置和资源。
- 恢复历史版本恢复的是配置引用，不自动回滚或删除云端文件；外部链接可用性不受本站保证。
- 初始兼容映射覆盖六个场景、作品分类和详情、联系浮层、音乐列表、标题及导航。
- 黑洞效果保留现有实现，仅开放有明确上下限的颜色、亮度、速度与尺寸参数；不开放后台代码注入。

## 10. 分发与运维

- 提供环境变量模板、管理员初始化命令、本机运行步骤和单机容器部署步骤。
- 数据库、本地上传及配置备份使用持久化目录；升级应用不能覆盖它们。
- 配置导出默认排除账号、会话和云密钥；完整数据备份另由服务器端工具生成并作为私密文件保存。
- 仓库包含代码、迁移、测试和允许分发的演示配置。现有个人媒体和凭证不自动提交。
- 对当前运行资源生成来源与分发许可清单。无法确认可分发的内容不捆绑；代码公开与素材公开分开处理。
- 前端深链接由应用回退到入口，管理、API、媒体及缺失静态资源不误回退为 HTML。
- 初版不支持仅静态托管、无持久磁盘部署或多个写入实例共享本地数据。

## 11. 验收与测试

1. 未登录无法读取管理私有配置、上传、发布、恢复或修改账号，旧 API 不能绕过认证。
2. 初始账号创建、错误登录限流、退出、过期、改密和 CSRF 用例通过。
3. 本地上传通过真实文件校验，能够在前台展示，重启后资源和配置仍存在。
4. S3 适配器通过兼容测试服务的真实写入/读取/清理验证；有实际云账号时补充真实部署验证，没有凭证时明确标注未验证具体云厂商。
5. 外链可直接引用；错误地址、非媒体地址、跨域受限及不支持模型能得到明确错误，不能误报成功。
6. 切换默认存储不破坏旧引用；凭证不出现在前台数据、日志、导出、版本库和可公开下载文件中。
7. 替换图片、视频、音乐与模型各完成一次端到端验证；无效上传或转换失败不影响线上效果。
8. 六场景配置项逐项验证映射；现有 Logo、黑洞、作品详情、导航、移动布局和音频开关回归通过。
9. 发布冲突、构建中断和版本恢复测试通过，不出现混合版本。
10. 未改动的 Git 工作区内容保持原样；从干净环境按说明可启动基础站点与后台，并明确报告演示素材的提供方式。
