# 个人网站管理后台

本版本在保留当前 3D 前台的基础上增加 `/admin/` 工作台。它是单站点、单管理员、自托管服务，不提供公开注册。云存储采用通用 S3 兼容 API，不绑定特定厂商。

## 本地启动

需要 Node.js 24 或更新版本。当前使用 Node 内置 `node:sqlite`；Node 24 会输出该模块的 ExperimentalWarning，这是运行时提示，不是数据库打开失败。

```sh
npm ci
# 按 .env.example 新建 .env；不要覆盖已有配置。
npm run admin:init
npm run dev
```

打开 `http://localhost:3000/admin/`。初始化在服务器终端交互完成，密码隐藏输入，至少 12 个字符；没有内置账号或默认密码，也不能从公网抢先注册。忘记密码执行 `npm run admin:reset`，按提示输入 `RESET`；该操作使原登录会话失效。

数据库和上传文件默认位于 `data/`，不通过静态目录公开，不应提交 Git。不要删除这个目录来“重新启动”。工作台可以管理：

- 网站标题、导航文字、联系信息、实验室链接和音乐列表。
- 当前 UIL 中六个场景的已识别文案、材质/纹理、模型和部分数值参数。
- 作品信息、视频、标志、封面与排序。
- 本地/S3 上传、HTTPS 外链、资源回收与模型转换。
- 草稿、登录态预览、发布记录及历史恢复。

保存只更新草稿。预览需要管理员登录；发布后访客才读取新版本。恢复历史版本也只是恢复到草稿，需检查后再次发布。配置版本不会恢复被手动修改的原始程序、字体或资源文件，请一并备份。

## 配置 S3

1. 在服务器执行 `npm run admin:key`，将生成的 64 位十六进制值保存到 `.env` 的 `SITE_MASTER_KEY`。不要上传、截图或提交此值。
2. 重启服务，在「存储设置」新建 S3 配置，填写名称、Endpoint、Region、Bucket、可选路径前缀、Access Key ID、Secret Access Key；临时凭证可填写 Session Token。
3. 按服务商要求选择 Path-style。默认 Region 可填 `us-east-1`，但部分服务必须使用实际区域。
4. **公开访问基地址**填写面向访客的 Bucket 公网地址或 CDN 域名，例如 `https://media.example.com/site`。不可含查询参数、fragment 或密码。它不是管理 API Endpoint，系统会在其后追加对象 Key。
5. 运行只读连接测试，并上传一个小文件，在前台预览其访问、渲染及 CORS 行为后再发布。

凭证由服务端用 AES-256-GCM 加密，读取配置时仅返回 `configured` 标志。密钥字段留空代表保留原值。`SITE_MASTER_KEY` 丢失或改变后，旧凭证无法解密，必须重新填写；数据库与主密钥应分开备份。

连接测试使用 HeadBucket，不会创建桶、设置 ACL、修改 CORS 或删除对象。它只证明该凭证可以进行该检查；不证明上传权限、公网 URL、CDN 或跨域加载可用。某些只有前缀权限的账号可能无法执行 HeadBucket，但具备对象操作权限，需要按服务商策略配置。

对象存储应仅给后台账号授权指定 Bucket/前缀所需对象操作，不使用云账号根密钥。公开访问策略和 CORS 由部署者在存储服务设置：允许网站来源读取 GET/HEAD（3D 纹理/模型需要跨域读取），按需要暴露 ETag、Content-Length、Accept-Ranges 等响应头。上传走后台，不需要让浏览器获得 S3 密钥。

默认禁止内网/回环/元数据地址作为 Endpoint，DNS 解析结果会固定到通过检查的地址。确需自托管内网 S3 时，由服务器管理员在 `S3_ENDPOINT_ALLOWLIST` 中列出准确的 Endpoint origin；不要使用泛域名。生产仍要求 HTTPS。只对你控制的服务配置该例外。

已有资源后，不能直接改该配置的 Endpoint、Bucket、前缀、公开地址或寻址方式；请新增存储配置。切换默认存储只影响以后上传的文件，不会迁移已有文件。

## 文件与模型

支持 PNG/JPEG/GIF/WebP/AVIF、MP4/WebM、MP3/WAV/OGG/Opus 和静态 GLB。文件按真实签名判断，不信任扩展名。单文件上限：图片 25 MiB、音频 100 MiB、模型 200 MiB、视频 1 GiB。SVG、HTML、脚本和任意程序文件不允许上传。

GLB 上传后需在资源库执行「转换为场景模型」，指定尺寸后生成该引擎使用的 BIN。转换在受限子进程中执行，保留源文件，转换后在模型槽位选择新资源。支持静态三角网格及节点变换；不支持骨骼、动画、压缩 GLB、稀疏 accessor 等。超过面数/时间限制会明确报错。材质沿用原场景设置，不导入 GLB 的全部材质/贴图。

资源只有被发布版本引用后才对匿名用户开放。已发布或被历史版本引用的文件不能回收，以保证历史配置仍可使用。当前回收为逻辑回收，不会物理删除云对象；版本和资源数据可能随使用增长，需要容量监控。外部链接只记录引用，不会自动下载、搬迁或持久化对方文件。

## 当前边界

- 不是通用可视化 3D 编辑器：只开放已识别的配置槽位，不能编辑全部着色器、动画逻辑、位置旋转或引擎代码。
- 3D 字体是有限字形图集。发布/预览会检查修改后的 3D 文案，缺字时拒绝并提示，**尚未提供后台自动重建字体**。普通网页标题不受此限制。原字体和素材授权由部署者确认。
- S3 和外链使用长期公网/CDN 地址；不支持私有桶签名链接自动续期。真实公网访问/CORS 必须在最终域名上验证；保存外链不会由服务器抓取任意地址。
- 单实例 SQLite + 持久磁盘；不支持多副本共用 SQLite 或无持久盘的 Serverless。单次模型处理是同步请求，最多 120 秒，不是断点恢复任务队列。
- 发布固定配置快照，但原始运行包/字体/第三方外链不是内容寻址快照；升级这些文件可能影响历史页面。

## 公网部署

生产环境示例（自行填写，不提交真实 `.env`）：

```dotenv
NODE_ENV=production
HOST=127.0.0.1
PORT=3000
SITE_ORIGIN=https://your-domain.example
SITE_DATA_DIR=/var/lib/personal-site
SITE_MASTER_KEY=填入本机生成的64位十六进制密钥
TRUST_PROXY=loopback
```

让受信任的反向代理提供 HTTPS，并把请求转发到服务端。不要把 Node 开发 HTTP 直接暴露公网。仅在确实使用代理时设置准确的 `TRUST_PROXY`，不要盲目使用 `true`。代理须覆盖上面的上传大小，并给模型转换至少 150 秒超时。站点 Origin 必须与用户登录地址完全一致，否则写入会因来源校验而拒绝。

提供 `Dockerfile` 和 `compose.yaml` 作为单实例部署模板。先准备授权的 `assets/`，设置 `.env` 中真实域名、主密钥及代理参数，再执行：

```sh
docker compose build
docker compose run --rm -it site npm run admin:init
docker compose up -d
```

容器仅映射到宿主机 `127.0.0.1:3000`，前面仍需 HTTPS 代理。命名卷保存 `/app/data`，资源目录只读挂载。**不要执行 `docker compose down -v`，它会删除数据库和上传文件。** Docker 模板需在目标服务器验证，本次本地测试不等同于容器部署验收。

备份时先停止实例，复制整个私有数据目录（含 SQLite WAL/SHM 如存在），单独加密保管主密钥，再启动；另行备份授权运行资源。S3 对象备份/版本控制由存储服务负责。恢复先在隔离环境验证，不能只备份 `site.db` 而忽略上传文件。

## 发布到 GitHub 前

`assets/`、`data/`、`.env` 默认不提交。此项目原有 3D 运行代码、字体、模型、音乐和示例 CMS 内容并非自动获得开源再分发授权：请确认权利，替换不属于你的品牌、项目、媒体和字体，清理示例中的私人资料及链接，再选择适用许可证。

全新克隆没有忽略的运行资源包，不能视为开箱即用的完整 3D 网站。需要自行提供授权的 assets 包。后台不会在生产运行时静默向原站回源下载资源。原有下载脚本仅保留作历史开发工具，不是已授权的资源分发方案。
