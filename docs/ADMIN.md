# 个人网站管理后台

本版本在保留当前 3D 前台的基础上增加 `/admin/` 工作台。它是单站点、单管理员、自托管服务，不提供公开注册。云存储采用通用 S3 兼容 API，不绑定特定厂商。

## 本地启动

需要 Node.js 24 或更新版本、独立 PostgreSQL 18 数据库。运行时不使用 SQLite；`node:sqlite` 只用于显式只读旧站导入。

```sh
npm ci
# 按 .env.example 新建 .env；不要覆盖已有配置。
# 配置 DATABASE_URL；本地生成 SETUP_TOKEN（至少 32 随机字节的 hex）。
npm run dev
```

打开与 `SITE_ORIGIN` 一致的 `/admin/`，依次授权安装、检查数据库、预检来源、设置管理员、确认安装。没有内置账号或默认密码；安装完成不会自动登录。`admin:init` 仅输出网页安装指引，不初始化数据库。忘记密码执行 `npm run admin:reset`，仅已安装实例可重置，该操作使原登录会话失效。

账号、配置、会话、版本和资源登记保存于 PostgreSQL；`data/uploads` 仅保存媒体字节。二者均需备份，不应提交 Git。不要删除数据目录或数据库来“重新启动”。工作台可以管理：

- 网站标题、导航文字、联系信息、底部展示区跳转链接和音乐列表。
- 当前 UIL 中六个场景的已识别文案，以及首页顶部 3D Logo。
- 开场背景视频与封面、底部六边形屏幕中的图片/GIF、联系链接、社媒图标及微信二维码。
- 作品信息、视频、标志、封面与排序。
- 本地/S3 上传、HTTPS 外链、资源回收与模型转换。
- 草稿、登录态预览、发布记录及历史恢复。

保存只更新草稿。预览需要管理员登录；发布后访客才读取新版本。恢复历史版本也只是恢复到草稿，需检查后再次发布。新发布固定程序及生成文件，媒体仍受资源状态/存储权限控制，不是全站媒体归档。

### 内容替换入口与固定视觉

| 要替换的内容 | 后台位置 | 说明 |
| --- | --- | --- |
| 顶部 3D Logo | 场景配置 → Home → 顶部 3D Logo | 可先在旁边的腾讯混元 3D 链接生成并下载静态 GLB；此槽位上传 GLB 后自动转换为 BIN，保留原 GLB，并可在资源库手动重试转换。不是所有 GLB 特性都支持。 |
| 开场视频、未播放时的封面 | 网站设置 → 开场与底部展示 | 该视频被原引擎的多处视频表面共享，不仅是普通网页背景；确认前台预览后再发布。 |
| 底部六边形屏幕中的画面 | 网站设置 → 开场与底部展示 → 底部六边形屏内容 | 替换图片/GIF 内容，不改变六边形结构、着色器或反射纹理。联系页的金属/玻璃背景属于固定视觉，不在此设置。 |
| HOME / JOIN US / ABOUT US | 网站设置 → 联系页面链接 | 三项文字和 HTTPS 跳转地址可分别设置。 |
| 三个社媒入口 | 网站设置 → 社交媒体 | 名称、HTTPS 地址、图标图片分别配置；图标建议透明 PNG/WebP。名称用于无障碍说明，不额外添加可见文字。 |
| 微信二维码 | 网站设置 → 微信二维码 | 上传带完整边距的方形二维码原图；显示时不更改二维码内容、不反色，沿用原站仅桌面显示的规则。发布前用手机实际检查识别。 |

上述新增内容留空或不存在时沿用原站行为，打开界面不会自动写入默认值。媒体可从资源库选择，或填写已授权的 HTTPS 公网链接；外链公开访问与 CORS 仍需在最终站点实际验收。图片槽位不能使用视频/音频，开场视频槽位只能使用视频。

系统贴图、材质、反射、灯光、粒子参数及内部模型不再显示为可编辑项，资源库也隐藏系统内置素材，但不会删除它们。保存接口会拒绝固定视觉字段的修改；当前已有值保留，历史恢复只恢复可编辑内容并沿用当前固定视觉值，既有历史快照不会被重写。

## 运行包、预览和历史交付

新安装可先创建账号、编辑内容，但没有已选择的完整运行包时不能预览/发布。在服务器执行明确清单的 `npm run runtime:register -- --root /srv/authorized-runtime --manifest /srv/runtime-manifest.json --profile legacy-six-scenes-v1`（示例路径需核对），再在后台刷新运行包列表、明确选择。登记不自动选择，选择不自动发布；包不是任意 JavaScript 上传入口。见[完整运维说明](ENGINE-RUNTIME.md)。

先保存草稿，再预览/发布。构建期间按钮禁用，避免重复提交；不要在网络超时后立即重试。请求可能已提交但响应丢失，应先刷新发布历史及审计，确认实际结果再决定下一步。构建失败不切换当前公开版本，预留版本号出现空洞正常。

认证预览有效期为最终提交起 30 分钟，每人最多五个；依赖也需要同一有效账号/会话，退出、重置账号或过期后延迟请求会被拒绝。预览响应为 private/no-store/noindex，不是可公开分享的静态网址。选择另一包不会替换已有公开版本、历史或有效预览的程序字节。

从结构 1/2 显式升级后，旧历史标记为 legacy。尚无兼容交付时前台返回维护 503；登记/选择后为当前旧版本执行一次“生成兼容交付”，或恢复为草稿再新发布。兼容交付不是当年的程序重放，也不能重复绑定覆盖。修改包、内容或 SITE_ORIGIN 应新发布；旧域名绑定不会自动改写，后台仍可读取历史。

### 网站描述、语言与分享图片

“网站设置 → 搜索与分享”可以配置描述、页面语言和默认分享图片。修改仍需先保存草稿，再预览和发布。语言设置不会自动翻译内容；描述不受 3D 字体字形限制。作品详情优先使用该作品的描述和 image 图片，缺省时使用网站设置。

canonical 与分享 URL 的域名来自服务器 SITE_ORIGIN，不能在浏览器里填写另一个域名。分享图必须是已登记的图片或经登记的 HTTPS 外链；清空只影响新草稿/新发布版本，不删除历史版本使用的资源。

旧版本恢复只改变草稿，并以空描述、en 语言、空分享图补齐缺失字段。既有历史快照不被改写；旧引擎 metadata.json 接口保持原语义。

## 配置 S3

1. 在服务器执行 `npm run admin:key`，将生成的 64 位十六进制值保存到 `.env` 的 `SITE_MASTER_KEY`。不要上传、截图或提交此值。
2. 重启服务，在「存储设置」新建 S3 配置，填写名称、Endpoint、Region、Bucket、可选路径前缀、Access Key ID、Secret Access Key；临时凭证可填写 Session Token。
3. 按服务商要求选择 Path-style。默认 Region 可填 `us-east-1`，但部分服务必须使用实际区域。
4. **公开访问基地址**填写面向访客的 Bucket 公网地址或 CDN 域名，例如 `https://media.example.com/site`。不可含查询参数、fragment 或密码。它不是管理 API Endpoint，系统会在其后追加对象 Key。
5. 运行只读连接测试，并上传一个小文件，在前台预览其访问、渲染及 CORS 行为后再发布。

凭证由服务端用 AES-256-GCM 加密，读取配置时仅返回 `configured` 标志。密钥字段留空代表保留原值。`SITE_MASTER_KEY` 丢失或改变后，旧凭证无法解密，必须重新填写；数据库与主密钥应分开备份。

连接测试使用 HeadBucket，不会创建桶、设置 ACL、修改 CORS 或删除对象。它只证明该凭证可以进行该检查；不证明上传权限、公网 URL、CDN 或跨域加载可用。某些只有前缀权限的账号可能无法执行 HeadBucket，但具备对象操作权限，需要按服务商策略配置。

对象存储应仅给后台账号授权指定 Bucket/前缀所需对象操作，不使用云账号根密钥。公开访问策略和 CORS 由部署者在存储服务设置：允许网站来源读取 GET/HEAD（3D 纹理/模型需要跨域读取），按需要暴露 ETag、Content-Length、Accept-Ranges 等响应头。上传走后台，不需要让浏览器获得 S3 密钥。

默认禁止内网/回环/元数据地址作为 Endpoint，DNS 解析结果会固定到通过检查的地址。确需自托管内网 S3 时，由服务器管理员在 `S3_ENDPOINT_ALLOWLIST` 中列出准确的 Endpoint origin；不要使用泛域名。生产仍要求 HTTPS。只对你控制的服务配置该例外。

已有资源后，不能直接改该配置的 Endpoint、Bucket、前缀、公开地址或寻址方式；请新增存储配置。切换默认存储只影响以后上传的文件，不会迁移已有文件。

## 文件与模型

支持 PNG/JPEG/GIF/WebP/AVIF、MP4/WebM、MP3/WAV/OGG/Opus 和静态 GLB。文件按真实签名判断，不信任扩展名。单文件上限：图片 25 MiB、音频 100 MiB、模型 200 MiB、视频 1 GiB。SVG、HTML、脚本和任意程序文件不允许上传。

顶部 3D Logo 槽位上传 GLB 后会自动转换并选用 BIN；普通资源上传仍可在资源库执行「转换为场景模型」，指定尺寸后生成该引擎使用的 BIN。转换在受限子进程中执行，保留源文件。支持静态三角网格及节点变换；不支持骨骼、动画、压缩 GLB、稀疏 accessor 等。超过面数/时间限制会明确报错。材质沿用原场景设置，不导入 GLB 的全部材质/贴图。

资源只有被发布版本引用后才对匿名用户开放。已发布或被历史版本引用的文件不能回收，以保证历史配置仍可使用。当前回收为逻辑回收，不会物理删除云对象；版本和资源数据可能随使用增长，需要容量监控。外部链接只记录引用，不会自动下载、搬迁或持久化对方文件。

## 当前边界

- 不是通用可视化 3D 编辑器：仅开放业务内容、已识别文案和顶部 Logo，固定视觉参数、内部模型、着色器与引擎代码不可编辑。
- 3D 字体是有限字形图集。发布/预览会检查修改后的 3D 文案，缺字时拒绝并提示，**尚未提供后台自动重建字体**。普通网页标题不受此限制。原字体和素材授权由部署者确认。
- S3 和外链使用长期公网/CDN 地址；不支持私有桶签名链接自动续期。真实公网访问/CORS 必须在最终域名上验证；保存外链不会由服务器抓取任意地址。
- PostgreSQL + 持久媒体磁盘；部署模板仍为单应用实例。数据库共享不等于本地媒体、安装限流或模型并发控制已支持多副本。单次模型处理是同步请求，最多 120 秒，不是断点恢复任务队列。
- 新发布的程序、shader 和生成文件固定到私有交付；字体、普通媒体、S3 和外链仍受资源服务控制，不承诺这些媒体永久不变。完整原六场景视觉需要独立素材与浏览器验收。

## 公网部署

生产环境示例（自行填写，不提交真实 `.env`）：

```dotenv
NODE_ENV=production
HOST=127.0.0.1
PORT=3000
SITE_ORIGIN=https://your-domain.example
DATABASE_URL=postgresql://site_app:URL编码的应用密码@数据库地址:5432/personal_site
SETUP_TOKEN=首次安装用的本机随机hex令牌
SITE_DATA_DIR=/var/lib/personal-site
SITE_MASTER_KEY=填入本机生成的64位十六进制密钥
TRUST_PROXY=loopback
```

让受信任的反向代理提供 HTTPS，并把请求转发到服务端。不要把 Node 开发 HTTP 直接暴露公网。仅在确实使用代理时设置准确的 `TRUST_PROXY`，不要盲目使用 `true`。代理须覆盖上面的上传大小，并给模型转换至少 150 秒超时。站点 Origin 必须与用户登录地址完全一致，否则写入会因来源校验而拒绝。

提供 `Dockerfile`、内置 PostgreSQL 的 `compose.yaml` 和仅外部数据库的 `compose.external.yaml`。部署密码/令牌放在权限为 0600 的服务器环境文件；不要覆盖现有 `.env`。完整命令、权限和停机迁移门槛见 [PostgreSQL 部署迁移指南](POSTGRESQL-MIGRATION.md)。内置数据库示例：

```sh
docker compose --env-file .env.deployment -p personal-site -f compose.yaml config --quiet
docker compose --env-file .env.deployment -p personal-site -f compose.yaml up -d --build --wait
# 经 HTTPS 代理访问 /admin/ 完成首次安装；不会自动创建管理员。
```

应用端口仅映射宿主机回环地址，可通过 `SITE_PORT` 改变；数据库无宿主机端口映射。命名卷分别保存 `/app/data` 与 PostgreSQL 18 的 `/var/lib/postgresql`，资源目录只读挂载。**不要对真实部署执行 `docker compose down -v`，它会删除数据库和上传文件。** 本地隔离容器验收记录见 [实际验证](verification/postgresql-installation.md)，不能替代目标服务器验收。

备份时进入维护窗口停止应用写入/新构建并等待在途结束，对 PostgreSQL 执行 `pg_dump -Fc`，同时备份完整私有 data（含 delivery、uploads）、授权 bundled 媒体及原运行包/清单；独立加密保管主密钥。S3 对象备份/版本控制由存储服务负责。恢复必须先到新独立数据库及新目录，核对行数、CAS 摘要、账号登录、预览授权和媒体读取；上线后的 PostgreSQL 新写入不能被旧 SQLite 备份覆盖。`npm run delivery:audit` 不删除任何对象，孤立/非当前公开不等于可删，第一版无自动 GC。

## 发布到 GitHub 前

`assets/`、`data/`、`.env` 默认不提交。此项目原有 3D 运行代码、字体、模型、音乐和示例 CMS 内容并非自动获得开源再分发授权：请确认权利，替换不属于你的品牌、项目、媒体和字体，清理示例中的私人资料及链接，再选择适用许可证。

全新克隆没有忽略的运行资源包，不能视为开箱即用的完整 3D 网站。需要自行提供授权的 assets 包。后台不会在生产运行时静默向原站回源下载资源。原有下载脚本仅保留作历史开发工具，不是已授权的资源分发方案。
